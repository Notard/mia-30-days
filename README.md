# 미아와 일주일

용세권의 미아와 한강이 내려다보이는 펜트하우스에서 일주일을 보내는 선택형 웹게임입니다. 그림전·식탁·탐험·우리집 중 목표를 고르고, 하루 두 번의 활동과 사건 선택을 통해 미아의 성장과 엔딩을 바꿀 수 있습니다.

## 플레이

[브라우저에서 게임하기](https://notard.github.io/mia-30-days/)

별도 설치 없이 최신 브라우저에서 실행됩니다. 저장 기록은 사용 중인 브라우저의 로컬 저장소에 남습니다.

## 파일

저장소 루트의 `index.html`을 열면 게임이 시작됩니다. JavaScript와 CSS는 빌드 없이 실행되는 게임 소스이며, `assets/`에는 실행에 필요한 그림·스프라이트·음성이 들어 있습니다. 로컬에서 확인하려면 이 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`을 여세요.

캐릭터, 그림, 음성 및 게임 자료의 공개는 재사용 허가를 뜻하지 않습니다. 별도의 라이선스는 부여되지 않았습니다.
